# Petal-and-verse
​Petal &amp; Verse 🌸 ​A serene, botanical poetry writing and inspiration studio. ​Petal &amp; Verse is a lightweight, distraction-free progressive web application (PWA) designed for poets, writers, and dreamers. Blending the tactile beauty of vintage flora with modern writing tools, it provides a peaceful digital canvas to compose, and style verse.
